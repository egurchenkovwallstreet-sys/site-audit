# Формат платных отчётов (без GigaChat)

Шаблоны генерируются сервисом из findings скана. LLM не используется.

## Тарифы

| Тариф | Код | Содержание |
|-------|-----|------------|
| **490 ₽** | `short` | **Сводка сумм КоАП**, охват, затем **4 раздела**: штрафы 152/168‑ФЗ, риски, доступ, SEO — по каждому пункту суть, норма, **ориентиры штрафов** (без «что сделать»). |
| **990 ₽** | `extended` | **Резюме** + **то же, что в кратком** + **подробные рекомендации** (как убрать штрафы → уязвимости → SEO) |

До оплаты (фаза B) — только превью на экране; полный текст отчёта — после подтверждения оплаты. На фазе A API превью может отдавать текст для отладки.

## Обязательные элементы в **обоих** отчётах

1. **Сводка штрафов** — суммы верхних границ по compliance и security (отдельно первичное и повтор).
2. **На каждый finding с penalty_code** — строка вида:  
   `КоАП РФ ст. 13.11 ч. X: https://www.consultant.ru/document/cons_doc_LAW_34661/...`
3. **Суммы** — ИП, юрлицо; при наличии в справочнике — повторное (ч. 1.1, 5.1 и т.д.).
4. **Охват** — `pages_checked`, список URL, оговорки если политика/cookie не прочитаны.
5. **Дисклеймер** — ориентиры КоАП, не юрзаключение.

SEO-пункты: явно указать, что штрафы КоАП по st. 13.11 обычно не применяются.

## API (черновик)

`GET /api/scans/{id}/paid-report?variant=short|extended` — Markdown, только `status=completed`.

Реализация: `backend/app/reports/compose.py`.

## Скачивание в UI

После завершения скана на `/check/{id}`:

- **Скачать отчёт** — `GET /api/scans/{id}/paid-report/download?variant=short` (HTML, вложение).
- **Скачать расширенный отчёт** — `variant=extended`.

Файл `.html` с типографикой и печатными стилями; PDF — через «Печать → Сохранить как PDF» в браузере.

Фаза B: тот же HTML; опционально серверный PDF (WeasyPrint).
