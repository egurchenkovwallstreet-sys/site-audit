# Политика отчётов и честности проверки

Согласовано с заказчиком. Источник для агента: `.cursor/rules/report-antibot-policy.mdc`.

## Антибот и неполная проверка

1. Показываем признаки защиты от ботов и ограничения доступа.
2. Разделяем: **что проверили** (список страниц, scope) и **что не проверяли** (форма, политика по тексту, cookie на закрытых URL).
3. Нельзя утверждать отсутствие штрафов по 152-ФЗ, если охват неполный или HTML не прочитан.
4. В выдаче — только обоснованные факты и технический прогноз (сценарии при реализации уязвимости).

## Платные отчёты (990 ₽ / 1990 ₽)

| Этап | Поведение |
|------|-----------|
| До оплаты | Превью: часть проблем на экране, статус проверки, без полного платного отчёта (PDF, файлы) |
| После оплаты | Полный отчёт **short (990 ₽)** или **extended (1990 ₽)** по шаблонам с КоАП, ссылками и суммами — см. `docs/paid-report-format.md` (без GigaChat) |

Отчёт **не генерируется автоматически**, если сайт не открылся или проверка оборвалась — сначала согласие пользователя и оплата.

Правило действует **в том числе**, если проблемы уже найдены: любой полный отчёт только после оплаты.
