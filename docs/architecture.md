# Архитектура

- `frontend/` — Next.js, пользовательский интерфейс.
- `backend/` — FastAPI, API и бизнес-логика.
- `scanner/` — изолированные интеграции сканеров.
- PostgreSQL — основное хранилище (добавляется на шаге 2).

Локально frontend доступен на `http://localhost:3000`, backend — на
`http://localhost:8000`.
