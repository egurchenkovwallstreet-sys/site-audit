## Шаг 1. Какой сервер выбрать

Подойдёт машина, где:

- **ОС:** Linux (Ubuntu / Debian) — удобнее всего.
- **Свободно RAM:** не меньше **2 GB** (для MVP без ZAP); **4 GB+** — лучше, когда добавим сканеры.
- **Диск:** хотя бы **15–20 GB** свободно под Docker-образы.
- **Порты 80 и 443** не заняты другим сайтом (или вы готовы повесить наш проект на этот IP вместо старого).
- Проект **не смешиваем** с чужими контейнерами в одной папке — отдельная директория, например `~/apps/site-audit`.

### Что выполнить на каждом из 3 серверов

Зайдите по SSH (подставьте свои данные):

```bash
ssh ВАШ_ЛОГИН@IP_СЕРВЕРА
```

Скопируйте и вставьте **одним блоком**:

```bash
echo "=== Имя хоста ==="
hostname
echo "=== ОС ==="
cat /etc/os-release 2>/dev/null | head -5
echo "=== Память ==="
free -h
echo "=== Диск ==="
df -h /
echo "=== CPU (ядер) ==="
nproc
echo "=== Docker (если есть) ==="
docker --version 2>/dev/null || echo "Docker не установлен"
echo "=== Кто слушает 80 и 443 ==="
sudo ss -tlnp | grep -E ':80|:443' || echo "80/443 свободны или нет прав"
echo "=== Запущенные контейнеры ==="
docker ps --format 'table {{.Names}}\t{{.Ports}}' 2>/dev/null || echo "нет docker/ps"
```

### Как решить

| Ситуация | Рекомендация |
|----------|--------------|
| Уже крутится важный прод на 80/443 | Берите **другой** VPS или другой IP |
| RAM < 1.5 GB | Слабовато; лучше другой сервер |
| 2–4 GB, 80/443 свободны | **Подходит** для старта |
| Тот же сервер, где тяжёлый проект | Можно, но отдельная папка и следите за RAM |

**Пришлите в чат** вывод с **трёх** серверов (или таблицу: IP → RAM → свободен ли 80). Я скажу, какой брать.
